# Implementación del primer recorrido de SEOBESTIA

Objetivo. Dar de alta un sitio, revisar su estado, usar una oportunidad en un brief y seguir una intervención en la pantalla Hoy.

| Unidad | Implementación | Comprobación |
|---|---|---|
| Persistencia y acceso | `lib/store.mjs` y `lib/auth.mjs`. SQLite para la prueba local, PostgreSQL para alojamiento. | Reabrir los datos, comprobar aislamiento, recuperar bloqueo y restaurar una copia. |
| Auditoría y oportunidades | `lib/crawl.mjs` y `lib/seo.mjs`. Extraer evidencia de URLs autorizadas y asociar consultas a páginas. | Casos técnicos conocidos, long-tail observada y sugerencia sin volumen. |
| Fuentes y revisión | Lectura GSC, importación CSV, ejecución por fecha local y tarea persistida. | Datos revisados sin doble conteo y errores de fuente visibles. |
| Interfaz e integración | `public/`, API y servidor local. Crear y editar un brief, registrar aplicación externa y consultar resultados. | Recorrer el flujo desde la API, comprobar UI y ejecutar la suite con npm test. |
| Operación real | Adaptadores Netlify, credenciales fuera del código y respaldo recuperable. | Tras conectar cuentas, medir dos ciclos diarios sin interacción y cuotas reales. |
